# Little Quizzy 📚

Little Quizzy is an interactive quiz application built with **SwiftUI** to demonstrate modern iOS development practices.

## ✨ Features
- **MVVM Architecture** for clean code organization.
- **Custom Navigation Path Routing** for flexible navigation.
- **SwiftData** for persistent quiz score storage.
- **Light & Dark Mode** support.
- **Animated Score Cards** with smooth transitions.
- **Reusable UI Components** for a consistent user experience.
- **Interactive Quizzes** with subject-based and random quiz modes.

## 🛠️ Technologies
- Swift
- SwiftUI
- SwiftData
- MVVM
- Custom Navigation & Routing

## 🎯 Purpose
This project demonstrates practical SwiftUI development, state management, data persistence, navigation, and reusable UI design.
