# Little Quizzy 📚

Little Quizzy is an interactive quiz application built with **SwiftUI**, demonstrating modern iOS development practices and a clean, reusable architecture.

## 🎬 App Demo

Watch the Little Quizzy demo to explore its interactive quizzes, custom navigation, and animated UI.

📱 **[Watch Little Quizzy Demo Video](https://drive.google.com/file/d/15TFzfdxcjfoFoejqCx7eNmEmicaC_lBq/view?usp=sharing)**

## ✨ Features

- 🏗️ **MVVM Architecture** for clean code organization.
- 🧭 **Custom Navigation Path Routing** for flexible and seamless navigation.
- 💾 **SwiftData** for persistent quiz score storage.
- 🌗 **Light & Dark Mode** support.
- 🎯 **Animated Score Cards** with smooth transitions.
- 🧩 **Reusable UI Components** for a consistent user experience.
- 📚 **Subject-Based Quizzes** across multiple subjects.
- 🎲 **Random Quiz Mode** for interactive practice.
- 🏆 **Quiz Results and Score Tracking** to track quiz performance.

## 🛠️ Technologies Used

- Swift
- SwiftUI
- SwiftData
- MVVM Architecture
- Custom Navigation and Routing
- State Management and Animations

## 🎯 Project Purpose

This project demonstrates practical iOS development skills, including SwiftUI interface development, navigation management, data persistence, state management, animations, and reusable component design.
